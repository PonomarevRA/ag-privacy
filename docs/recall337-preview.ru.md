# Экспериментальная модель ФИ и ФИО

[Русский](recall337-preview.ru.md) · [English](recall337-preview.en.md)

Выпуск добавляет опциональный .NET-ранжировщик интервалов ФИО в сообщениях логов, включая вложенный и экранированный JSON. Модель оценивает группы из двух–четырёх токенов по форме слов и ближайшему окружению. Полная маска скрывает все символы ФИО, точная также сохраняет исходные границы и окружающий текст.

## Запуск

В корне checkout экспериментального тега нужны .NET SDK 10.0.102 и Python 3. Команды рассчитаны на Linux и macOS.

```sh
demo_dir=$(mktemp -d)
python3 - "$demo_dir/demo.key" <<'PY'
import os
import secrets
import sys

with os.fdopen(os.open(sys.argv[1], os.O_WRONLY | os.O_CREAT | os.O_EXCL, 0o600), "wb") as key:
    key.write(secrets.token_bytes(32))
PY
dotnet build src/AgPrivacy.Cli -c Release
dotnet src/AgPrivacy.Cli/bin/Release/net10.0/AgPrivacy.Cli.dll stream-log \
  policies/default.json "$demo_dir/demo.key" preview "$demo_dir/journal.ndjson" \
  --log-analysis mixed --person-prose-model models/person-prose.bin \
  --structured-person-model models/person-span-recall337-preview.bin \
  < examples/generated/recall337_before.ndjson
```

Первые три строки показывают подстановки, следующие две сохраняют технический текст, а последняя показывает пропуск детектора. Опубликованный результат получен с фиксированным синтетическим ключом. При новом ключе подстановки будут другими. [Синтетический вход](../examples/generated/recall337_before.ndjson) · [Полученный результат](../examples/generated/recall337_after.ndjson)

Экспериментальная модель включается явно через `--structured-person-model`. Этот флаг также принимает прежний формат APNER. Новые веса загружает .NET CLI. Поддерживаемые веса для ONNX и WebNN описаны в их инструкциях.

## Проверка качества

Разобрали 337 неполных масок в 22 семействах. Добавили пары с ФИО и технической фразой и варианты с укороченными и расширенными границами. Порог выбрали на отдельной выборке разработки. В зафиксированном синтетическом тесте использовали другие семейства шаблонов и фамилий, по 500 положительных и технических строк на группу.

| Группа | Полные маски | Точные маски | Ложные маски технических строк |
|---|---:|---:|---:|
| RU, кириллица | 435/500 | 435/500 | 0/500 |
| RU, транслит | 494/500 | 431/500 | 10/500 |
| EN, кириллица | 486/500 | 486/500 | 33/500 |
| EN, транслит | 488/500 | 488/500 | 12/500 |
| Всего | 1 903/2 000 | 1 840/2 000 | 55/2 000 |

Полнота выросла с 87,55% до 95,15% относительно прежних экспериментальных весов. Условие 95% в каждой группе и бюджет 5 ложных масок на 1 000 технических строк пока не выполнены. При подаче 1 000 записей/с медиана p99 пяти локальных прогонов составила 923,63 мс против 22,44 мс у прежних весов. Кандидат обработал около 950 записей/с. Выпуск предназначен для оценки.
