# Данные публичной поставки

В поставку включены исходники библиотеки, CLI, локальный UI, адаптеры, веса моделей, форматные правила и синтетические тесты. Примеры в `examples/generated` получены запуском приложенного `examples/Quickstart`.

Примеры содержат вымышленные ФИО, телефонные значения и документы, зарезервированные домены для email и адреса IP из диапазонов документации. Исходные рабочие логи и документы не используются в этих примерах.

Файл `ru-names.txt` содержит адаптированный список личных имён из открытого источника. Источник и условия указаны в `notices/THIRD-PARTY-NOTICES.TXT`. Фамильный детектор содержит обученные числовые веса. Входные списки фамилий передаются тренеру внешними путями.

Исследовательские отчёты, локальные пути, персональные конфигурации, файлы ключей и учебные корпуса остаются за пределами этой поставки. Статусы тестов проверяются на конкретном исходном снимке. Полнота распознавания зависит от языка, формата данных и контекста.
