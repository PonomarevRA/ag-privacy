# Локальные модели

| Файл | Назначение |
| --- | --- |
| `models/person-default.bin` | Основной детектор интервалов ФИО |
| `models/person-prose.bin` | Дополнительный детектор ФИО и логинов внутри сообщения |
| `src/AgPrivacy.Core/Data/surname-shape.bin` | Встроенный классификатор формы фамилии |
| `models/*context-shadow*.bin`, `models/*id-shadow*.bin` | Дополнительные теневые наблюдатели контекста |

Модель ФИО — усреднённый линейный перцептрон с метками начала, продолжения и обычного слова. Признаки учитывают написание слова, начало и окончание, соседние слова, регистр и предыдущую метку. Хэширование признаков задаёт фиксированный объём памяти. Модель сохраняет коэффициенты int16.

Классификатор формы фамилии — логистическая модель. Он оценивает группы из двух, трёх и четырёх символов, включая границы слова. Файл весов имеет размер 65 544 байта. При обработке требуется проверка контекста, поскольку обычное слово может иметь похожее написание.

## Обучение ФИО

Подготовьте внешние UTF-8 JSONL-файлы обучения и проверки. Каждая запись содержит `text` и `entities` — пары `[start, length]` для полных интервалов ФИО в единицах UTF-16. Негативный пример имеет пустой массив `entities`.

```json
{"text":"Контакт: Алина Зорничева; принято","entities":[[9,15]]}
{"text":"Служба очереди подтвердила обработку","entities":[]}
```

```sh
dotnet run --project tools/AgPrivacy.Train -c Release -- \
  /path/to/train.jsonl /path/to/holdout.jsonl /path/to/person.bin 8192
```

Для продолжения обучения передайте начальный файл весов и число эпох от 1 до 24.

```sh
dotnet run --project tools/AgPrivacy.Train -c Release -- \
  /path/to/train.jsonl /path/to/holdout.jsonl /path/to/person.bin 8192 \
  models/person-prose.bin 1
```

Тренер ограничивает каждый файл 4 МиБ и 10 000 строками. Метрики тренера относятся к точному совпадению интервалов на переданной выборке. Качество полного конвейера проверяется отдельно через обычную точку входа обработки сообщений.

## Обучение формы фамилии

Нужны Python 3, NumPy, SciPy и scikit-learn. Фамилии и обычные слова передаются внешними файлами, по одному слову на строку.

```sh
python3 -m venv /path/to/training-env
/path/to/training-env/bin/python -m pip install numpy scipy scikit-learn
/path/to/training-env/bin/python tools/surname-model/train.py \
  /path/to/surnames.txt /path/to/negative-words.txt /path/to/surname-shape.bin
```

Обучение включает кириллицу и варианты транслитерации. Для интеграции нового классификатора замените ресурс `src/AgPrivacy.Core/Data/surname-shape.bin` и пересоберите библиотеку.

Фамилии одного семейства, варианты транслитерации и формулировки контекста распределяйте по отдельным наборам до обучения. Измеряйте полное покрытие размеченных фрагментов и ложные маски на технических строках. Проверяйте личности новых ложных срабатываний при сравнении версий. Результаты синтетики характеризуют проверенный набор.

Источник адаптированного списка имён и исходных фамилий для обучения описан в [third-party notices](../notices/THIRD-PARTY-NOTICES.TXT). Файлы с фамилиями в дистрибутив не входят.
