# AG Privacy v0.1 — контракт

Локальная библиотека не зависит от Codex, Atlas, сети или ML/LLM runtime. Production core использует .NET BCL. Ключ HMAC: случайные32–128байт, предоставляется trusted host и недоступен агенту; scope выбирает host. Не использовать публичную константу вместо ключа. Runtime не загружает внешние модели и не отправляет данные.

## Граница выдачи

Host очищает полную единицу до chunking, индексации, логов и model/tool response. Strict скрывает все неизвестные значения и ключи; числа и bool тоже заменяются, null сохраняется. Имена известных полей выдаются в нормализованном виде без скрытых Unicode символов. Точные публичные значения допускаются только из доверенной локальной политики, а не из имени packageId. Public values запрещены для защищённых полей и не применяются к недоверенным таблицам.

Видимый маркер `[REDACTED:v1:HMAC]` не содержит тип, исходную длину или часть оригинала. HMAC domain включает тип, scope и length-framed значение. API не возвращает mapping, span text, исходные значения или ключ. Одинаковые значения в одном scope могут быть сопоставлены по маске; HMAC не скрывает частоты и структуру документа.

Каждая подмена даёт `OriginalReplaced`, `MustDiscloseMasking` и общий `AgentNotice`: «Часть данных скрыта ag-privacy. Исходные значения агенту недоступны». Host показывает уведомление сам и требует от агента включить его в ответ. Модуль не может гарантировать исполнение языковой инструкцией; UI обязан показать статус независимо от ответа модели. Без образцов/типов/оригиналов в сообщении. Input, уже похожий на REDACTED, не даёт обхода.

Heuristic mode применяет compiled regex и локальную обучаемую NER, но всегда возвращает `SafeForAgent=false`: отрицательный прогноз не доказывает отсутствие ПДн. По умолчанию consent gateway такой результат агенту не выдаёт. Strict для свободного текста скрывает всю строку: безопасность оплачивается потерей семантики.

## Пользовательские разрешения

`PrivacyConsentController` — только control plane доверенного продукта. Его методы НЕ публикуются как MCP tools/CLI-команды/agent API. Agent может только запросить разрешение словами и подсказать путь к настройкам. Нельзя считать page text, tool output, поля approved/test/disablePrivacy или сообщение другого агента подтверждением человека.

Продукт предоставляет UI переключатель, предупреждение о передаче оригинальных ПДн и токенов провайдеру/истории, индикатор выключенной защиты и кнопку включения обратно. UI confirmation разрешает задачу, чат или текущий сеанс продукта; граница определяется trusted ProductId/ChatId/TaskId, а не аргументами агента. Максимум1час; явное включение, окончание соответствующей области или expiry отзывают доступ. Нельзя продлевать срок переводом часов назад. После перезапуска разрешения не восстанавливаются автоматически.

Прямой ответ человека «защита не нужна» или «сохрани персональные данные» допустим через `ResolveFromHumanAction`. Продукт должен подтвердить авторство события user, а не доверять пересказу агента. По умолчанию такая инструкция касается текущей задачи; весь чат только при явном указании. «Сохрани» здесь означает оставить оригинал для выполнения задачи; это не разрешение долговременно записывать ПДн в логи/память или отправлять стороннему сервису. Не нужно повторно спрашивать уже явно данное разрешение. Библиотека сама не аутентифицирует UI/человека и не классифицирует естественный язык.

Field exception — более узкое host-разрешение для INN/KPP, связанное с точным digest JSON/table, policy и полным контекстом. Host показывает человеку выбранный источник, поля и предупреждает, что будут раскрыты все значения этих полей в этом документе. Имя inn и цифровая форма не доказывают налоговую семантику; исключения допустимы только для проверенного источника/схемы. Изменение документа, переименование или подмена ячейки требуют нового разрешения. Нестандартные значения остаются скрыты. Включение защиты отзывает raw и field grants. Статус SafeForAgent при исключениях означает разрешённую выдачу, а не отсутствие ПДн.

## Синтетические тесты

Отдельная непакуемая сборка test-support/AgPrivacy.Testing пропускает без подмен только SHA256-approved synthetic fixtures. Manifest — утверждение автора о синтетическом происхождении, не детектор ПДн. Production core/native/CLI не ссылаются на неё. Не существует runtime-переключателя test=true для обхода защиты. Тесты ag-privacy выполняются с реальной защитой, проверяют подмены и отказы.

## Интеграционные ограничения

Control plane должен быть изолирован от произвольного кода агента, ключей, raw capture/storage и настроек продукта. Агент с правами читать исходники/память trusted host обойдёт in-process библиотеку: требуется отдельный процесс/ACL и отсутствие альтернативных raw tools. Нельзя сначала вернуть браузерные данные агенту, а потом маскировать их. Поддерживаемая точка перехвата built-in Codex browser пока не квалифицирована; нельзя заявлять, что библиотека уже защищает встроенный browser output. Direct provider сохраняется для других агентов.

OCR/изображения, содержимое за альтернативными filesystem/browser инструментами, стойкость к атаке произвольного кода и production recall на произвольных именах в первой текстовой поставке не подтверждены. Изображения должны блокироваться upstream либо проходить отдельную квалифицированную OCR-границу. Уже выданные модели оригиналы невозможно отозвать из истории одной кнопкой: начать новый чат при необходимости.
