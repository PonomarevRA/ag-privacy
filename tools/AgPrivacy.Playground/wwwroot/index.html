Проверка маскирования

Сравните исходные данные и результат маскирования.

Заменяет чувствительные значения целиком.

Обычные значения сохраняются. Чувствительные поля и распознанные значения маскируются.

Первая строка должна содержать заголовки.

Исключения полей JSON

По одному имени на строку. Регистр не важен. Для этих полей пропускается эвристика имён людей. Явные правила маскирования действуют.

До 256 КиБ текста в UTF-8. Для файлов CSV и TSV также поддерживается Windows-1251.

Для одного JSON покажет три режима. Подсветка отмечает места замены.
